# Local Discover and Deliver (LDD)

### A Team-Based MCA Mini Project

## About the Project

Local Discover and Deliver (LDD) is a web-based platform designed to help users discover local businesses and access convenient online ordering and delivery services.

The platform brings together customers, vendors, delivery partners, and administrators in one system.

## Key Features

- User Registration and Login
- Food Ordering
- Restaurant Listings
- Grocery Ordering
- Printing and Photocopy Services
- Vendor Dashboard
- Delivery Partner Dashboard
- Order and Payment Management
- Customer Feedback and Ratings
- Admin Dashboard

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, React (where applicable)
- **Backend:** PHP
- **Database:** MySQL / MariaDB
- **Development Environment:** XAMPP
- **Version Control:** Git and GitHub
